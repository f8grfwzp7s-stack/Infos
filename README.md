# Infos
Ce projet vise à transformer une vidéo brute en un rendu cinématographique professionnel, en appliquant des techniques de colorimétrie, de composition et de mise en scène inspirées du cinéma.  L’objectif est d’obtenir un rendu visuel plus immersif et qualitatif, avec un grading couleur soigné, un ratio d’image adapté (letterbox)
